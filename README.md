# rant-manager

Runs, stops and restarts a workspace's groups and nodes from the mesh.

```
rant install manager
rant run Manager
```

It offers a list of groups and a list of nodes under `<Prefix>/Rant`, each with a Manage
function beside it, as [docs/mesh.md](docs/mesh.md) lays out.

## Build

```
cargo build --release
```
